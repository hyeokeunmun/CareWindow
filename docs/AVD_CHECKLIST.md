# PLEOS AVD 수락 검증표

빌드 준비 항목 중 완료된 것은 아래 표시했습니다. 나머지 AVD 실행 항목은 **현재 실행하지 않았습니다.** 적합한 AVD에서 관찰 결과와 버전을 기록한 뒤 체크하세요. 예시 데이터나 일반 JVM 테스트로 대신 체크하지 않습니다.

## 준비

- [ ] AVD 이름/Android 버전, Vehicle SDK/Service 버전, NaviHelper/기본 Navi 앱 버전 기록.
- [x] JDK 17, Gradle 8.10.2, AGP 8.8.2, SDK 35로 lint/test/assemble 성공(2026-11-14).
- [x] debug APK v2 서명 및 SHA-256 기록. JVM UI 6개 검사 완료. 실제 설치/AVD 검증과 구분.
- [ ] 정확한 소스 revision, APK SHA-256, 설치 명령과 결과 보관.
- [ ] 공식 Vehicle/Navi 예제의 기본 연결이 해당 AVD에서 정상.

## 실제 읽기

- [ ] SOC 지원 기능 READ/READ_WRITE 확인. 미지원 차량은 정보 없음 표시.
- [ ] Virtual Console의 SOC 변경과 앱 정수 %가 일치.
- [ ] SOC null/범위 밖/권한 오류가 이전 값으로 추천되지 않음.
- [ ] 기본 Navi 앱 목적지·활성 여부·초 단위 ETA가 앱과 일치.
- [ ] 경로 취소, 목적지 변경, 경유지 변경, reroute가 이전 후보를 무효화.
- [ ] 순서를 바꾼 상태/목적지/경유지 콜백에서도 이전 경로의 빈 경유지 목록을 재사용하지 않음.
- [ ] 서비스 중단 후 데이터 만료가 표시되고 최신으로 갱신되지 않음.
- [ ] 경유지 응답 누락/15초 지연 후 자동 재조회가 중단되고 다시 연결이 필요함.

## 화면과 제한

- [ ] 초기 제한 상태가 없을 때 편집/경로 요청 잠금.
- [ ] 주행 제한 전환 시 열린 확인창이 닫히고 키보드가 숨겨짐.
- [ ] 화면 회전, 앱 background/foreground, 반복 연결에서 리스너 중복·크래시 없음.
- [ ] 뒤로가기/취소/반복 클릭, 작은 창/큰 창, 글꼴 확대와 스크린리더 검사.
- [ ] 실제 AVD에서 글자·터치 크기, 시스템 인셋, 스크롤 위치, 초 단위 갱신으로 인한 포커스 영향 검사.
- [ ] 일반 Android에서는 데모만 가능하고 PLEOS 실제 모드는 선택 불가.

## 출고된 안전 잠금 확인

- [ ] 가상 세 장소에는 실제 좌표가 없고 실제 전송이 불가능.
- [ ] 실제 시설 공급원 미연결 표시 및 빈 목록 확인.
- [ ] `NavigationWritePolicy.enabled == false`를 유지.
- [ ] 실제 `addWaypoint` 요청이 발생하지 않는 것을 기본 Navi 앱/계측으로 확인.

## 전송을 나중에 개발할 때의 별도 조건

다음은 잠금을 해제하기 위한 충분조건 전체가 아니라 반드시 다뤄야 할 위험 사례입니다.

- [ ] NaviHelper의 자동 큐/재연결 전송을 제어하는 공식 계약 확인.
- [ ] binder 단절 직전 사용자 확인 → 주행 상태 변화 → 재연결에도 오래된 요청이 실행되지 않음.
- [ ] 전송 중 프로세스 종료/재시작 시 자동 재전송 없음.
- [ ] 기존 경유지가 있거나 최신 목록을 못 얻으면 요청 중단.
- [ ] 사용자 확인 뒤 목적지·계획·시설 견적이 바뀌면 다시 확인.
- [ ] 요청 ID로 수락/거절/완료를 관측하거나, 불명확한 결과를 불명확하게 표시.
- [ ] 실패·타임아웃 뒤 기존 경유지를 확인하기 전 재요청 안 함.
- [ ] 검증된 시설과 실시간 경로 견적 공급원 통합 후 별도 개인정보/약관/안전 검토.
